# Internal historical documentation - not teammate assigned reading

The five module directories here preserve their previous guides, plans, contracts, usage notes,
delivery templates, request/response examples, dependency pointers and launchers. `project/` preserves
the previous repository overview and workflow documents. No working feature source was deleted.

These files describe the older layout; their relative paths and commands may be stale. Students use
only their current `MODULE/START_HERE.pdf` (or identical Markdown) and its named source/tests/samples.
Current source contracts remain in `shared/contracts/`; current setup is in the module's `run.ps1`.
